Fact Check

Verify claims against real sources — fully offline, right where you read them.

1. Start the local backend

This extension never sends anything to the cloud — it talks to a small server running on your own machine. Before verifying anything, start it once from a terminal: 

cd fact
venv\Scripts\python src\app.py

Leave that window open while you use the extension. If a check ever fails with "Could not reach the local Fact Check server", this is the first thing to check.

2. Verify text on any page

  1. Select a sentence or paragraph on any webpage.
  2. Right-click the selection and choose "Verify with Fact Check".
  3. A panel opens in the top-right with a live progress bar as each claim is checked, and the selected text on the page itself gets highlighted, color-coded by verdict, as each result comes in.
  4. Hover a highlight to see its confidence and which source it was compared against.

3. Or paste text directly

Click the toolbar icon to open the popup, paste in a sentence or paragraph, and click Verify. Useful for text that isn't already on a page — a document, an email, something someone said.

What the colors mean

  • Supported — a source was found that backs up the claim.
  • Contradicted — a source was found that disagrees with the claim.
  • Insufficient evidence — nothing found confident enough either way. Not the same as "false".

What this doesn't do (yet)

  • Opinions, predictions, and subjective statements are skipped on purpose — only checkable factual claims are verified.
  • Sources aren't identity-verified — a result titled like a well-known site isn't guaranteed to be that site's real domain.
  • Everything runs on your own CPU, so a claim can take a minute or more to check — the progress bar is there so you can see it's working, not stuck.
